# Weather MCP Server v1.0.0

This release turns the original prototype into a documented, tested MCP server for US weather data.

## Included

- `get-forecast` for National Weather Service forecasts by coordinate.
- `get-alerts` for active alerts by US state or territory code.
- Network-free tests for URL construction, validation, formatting, request headers, failure handling, and an end-to-end stdio MCP handshake.
- CI on Node.js 20 and 22.
- A locked dependency install and Dependabot coverage.
- Removal of 3,781 vendored dependency files from Git tracking.

## Scope

The server is read-only, stores no user data, and uses the stdio MCP transport.
Forecast coverage is limited to locations supported by the National Weather Service API.
